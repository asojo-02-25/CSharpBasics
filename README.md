# C# Basic Syntax Exercises

`src/CSharpBasics/BasicSyntaxProblems.cs` の各メソッドに問題文があります。
問題 1 から 15 は基本文法の確認、問題 16 から 25 は基礎文法を組み合わせて考える応用問題です。

## 実行方法

```bash
dotnet run --project src/CSharpBasics/CSharpBasics.csproj
```

## テスト方法

```bash
dotnet test
```

最初は各メソッドが `NotImplementedException` を投げるためテストは失敗します。
問題文に沿って正しく実装すると、対応するテストが通るようになります。
